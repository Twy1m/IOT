Arduino

O Arduino é a plataforma de prototipagem eletrônica mais usada para conectar sensores ao mundo digital. Nesta página você encontra suas características, como funciona e exemplos completos de programação para 12 dos sensores do catálogo.

O que é o Arduino

Arduino é uma plataforma de prototipagem eletrônica de código aberto (hardware e software), composta por uma placa com um microcontrolador e um ambiente de desenvolvimento (IDE) simplificado. Ele foi criado para facilitar a criação de projetos interativos, permitindo ler sinais de sensores e controlar atuadores (motores, relés, LEDs, displays) com poucas linhas de código em C/C++.

Como funciona

Todo programa Arduino (chamado de sketch) segue uma estrutura de duas funções principais: setup(), executada uma única vez ao ligar a placa (usada para configurar pinos e inicializar sensores/bibliotecas), e loop(), executada repetidamente enquanto a placa estiver ligada (usada para ler sensores, tomar decisões e acionar saídas). O microcontrolador possui conversores analógico-digitais (ADC) para ler sensores analógicos, pinos digitais para sensores on/off, e interfaces de comunicação (I2C, SPI, UART) para sensores digitais mais avançados.

Características técnicas (Arduino Uno)

Microcontrolador ATmega328P

Tensão de operação: 5V

14 pinos digitais (6 com PWM)

6 entradas analógicas (ADC de 10 bits)

32KB de memória Flash / 2KB SRAM

Programado em C/C++ pela IDE Arduino

Clock de 16MHz

Comunicação USB para upload e Serial Monitor

Tipos de sinal suportados

O Arduino se comunica com os sensores deste catálogo por meio de diferentes tipos de sinal, cada um adequado a um tipo de dado:

Analógico: lido pela função analogRead() nos pinos A0–A5, converte uma tensão (0–5V) em um valor de 0 a 1023 (ex.: LM35, LDR, MQ-2, ACS712).

Digital: lido/escrito pelas funções digitalRead() e digitalWrite(), representa apenas dois estados, alto ou baixo (ex.: PIR HC-SR501, SW-420, boia de nível).

I2C: barramento de 2 fios (SDA/SCL) que permite ligar vários sensores digitais ao mesmo tempo com endereços diferentes (ex.: BH1750).

SPI: barramento síncrono de 4 fios, mais rápido que o I2C, usado por módulos que exigem maior taxa de transferência (ex.: MFRC522).

DHT11 — Estação de temperatura e umidade com alarme de ventilação

Ligação: DHT11: VCC → 5V · GND → GND · DATA → pino digital 2 (com resistor de pull-up de 10kΩ entre DATA e VCC)

Biblioteca: DHT sensor library (Adafruit) — instale via Gerenciador de Bibliotecas da IDE

Página do sensor: DHT11

// ===================================================
// Leitura de temperatura e umidade com o DHT11
// Aciona um relé de ventilação quando a temperatura
// ultrapassa um limite de segurança
// ===================================================
#include <DHT.h>

#define DHTPIN 2        // Pino de dados do DHT11
#define DHTTYPE DHT11   // Define o modelo do sensor
#define PINO_RELE 8     // Pino que aciona o relé da ventilação

DHT dht(DHTPIN, DHTTYPE);
const float TEMP_LIMITE = 30.0; // Limite em °C para ligar a ventilação

void setup() {
  Serial.begin(9600);
  pinMode(PINO_RELE, OUTPUT);
  digitalWrite(PINO_RELE, LOW); // Ventilação começa desligada
  dht.begin();                  // Inicializa o sensor
}

void loop() {
  // Faz a leitura de umidade e temperatura (pode levar até 250ms)
  float umidade = dht.readHumidity();
  float temperatura = dht.readTemperature();

  // Verifica se a leitura falhou (erro de comunicação)
  if (isnan(umidade) || isnan(temperatura)) {
    Serial.println("Falha na leitura do sensor DHT11!");
    return;
  }

  Serial.print("Umidade: ");
  Serial.print(umidade);
  Serial.print(" %  Temperatura: ");
  Serial.print(temperatura);
  Serial.println(" C");

  // Liga a ventilação automaticamente se a temperatura for alta
  if (temperatura > TEMP_LIMITE) {
    digitalWrite(PINO_RELE, HIGH);
  } else {
    digitalWrite(PINO_RELE, LOW);
  }

  delay(2000); // O DHT11 não deve ser lido mais de 1x por segundo
}

DS18B20 — Leitura de múltiplas sondas de temperatura no mesmo barramento

Ligação: DS18B20: VCC → 5V · GND → GND · DATA → pino digital 4 (com resistor de pull-up de 4,7kΩ entre DATA e VCC)

Biblioteca: OneWire + DallasTemperature (Miles Burton) — instale via Gerenciador de Bibliotecas

Página do sensor: DS18B20

// ===================================================
// Leitura de temperatura com um ou mais sensores
// DS18B20 no mesmo barramento 1-Wire
// ===================================================
#include <OneWire.h>
#include <DallasTemperature.h>

#define PINO_BARRAMENTO 4 // Pino digital do barramento 1-Wire

OneWire oneWire(PINO_BARRAMENTO);
DallasTemperature sensores(&oneWire);

void setup() {
  Serial.begin(9600);
  sensores.begin(); // Inicializa a biblioteca e localiza os sensores

  int quantidade = sensores.getDeviceCount();
  Serial.print("Sensores DS18B20 encontrados: ");
  Serial.println(quantidade);
}

void loop() {
  sensores.requestTemperatures(); // Solicita a conversão a todos os sensores

  // Lê a temperatura de cada sensor pelo seu índice no barramento
  for (int i = 0; i < sensores.getDeviceCount(); i++) {
    float tempC = sensores.getTempCByIndex(i);
    Serial.print("Sensor ");
    Serial.print(i);
    Serial.print(": ");
    Serial.print(tempC);
    Serial.println(" C");
  }

  delay(1000);
}

LDR — Iluminação automática por luminosidade ambiente

Ligação: LDR em divisor de tensão: 5V → LDR → A0 → resistor 10kΩ → GND

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: LDR

// ===================================================
// Acende a iluminação automaticamente quando
// o ambiente escurece (leitura via LDR)
// ===================================================
#define PINO_LDR A0
#define PINO_RELE_LUZ 7

const int LIMITE_ESCURO = 300; // Ajustar conforme o ambiente (0-1023)

void setup() {
  Serial.begin(9600);
  pinMode(PINO_RELE_LUZ, OUTPUT);
}

void loop() {
  int leituraLuz = analogRead(PINO_LDR); // 0 (escuro) a 1023 (muito claro)

  Serial.print("Luminosidade: ");
  Serial.println(leituraLuz);

  // Quanto menor a leitura, mais escuro está o ambiente
  if (leituraLuz < LIMITE_ESCURO) {
    digitalWrite(PINO_RELE_LUZ, HIGH); // Liga a iluminação
  } else {
    digitalWrite(PINO_RELE_LUZ, LOW);  // Desliga a iluminação
  }

  delay(500);
}

HC-SR04 — Robô com desvio automático de obstáculos

Ligação: HC-SR04: VCC → 5V · GND → GND · TRIG → pino digital 9 · ECHO → pino digital 10

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: HC-SR04

// ===================================================
// Mede a distância até um obstáculo com o HC-SR04
// e sinaliza quando o objeto está muito próximo
// ===================================================
#define PINO_TRIG 9
#define PINO_ECHO 10
#define DISTANCIA_MINIMA 15 // cm

void setup() {
  Serial.begin(9600);
  pinMode(PINO_TRIG, OUTPUT);
  pinMode(PINO_ECHO, INPUT);
}

long medirDistanciaCm() {
  // Gera um pulso de 10 microssegundos no Trigger
  digitalWrite(PINO_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PINO_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PINO_TRIG, LOW);

  // Mede o tempo em que o Echo fica em nível alto (ida e volta do som)
  long duracao = pulseIn(PINO_ECHO, HIGH);

  // Converte o tempo em distância: velocidade do som ~ 0,0343 cm/us,
  // dividido por 2 porque o som percorre a distância duas vezes (ida e volta)
  long distanciaCm = duracao * 0.0343 / 2;
  return distanciaCm;
}

void loop() {
  long distancia = medirDistanciaCm();

  Serial.print("Distancia: ");
  Serial.print(distancia);
  Serial.println(" cm");

  if (distancia > 0 && distancia < DISTANCIA_MINIMA) {
    Serial.println("Obstaculo detectado! Desviando...");
    // Aqui entraria a lógica de desvio do robô
  }

  delay(200);
}

PIR HC-SR501 — Iluminação por presença com temporizador

Ligação: HC-SR501: VCC → 5V · GND → GND · OUT → pino digital 3

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: PIR HC-SR501

// ===================================================
// Liga a iluminação ao detectar movimento e mantém
// acesa por um tempo determinado após a detecção
// ===================================================
#define PINO_PIR 3
#define PINO_LAMPADA 6

const unsigned long TEMPO_ACESO = 30000; // 30 segundos
unsigned long ultimaDeteccao = 0;

void setup() {
  Serial.begin(9600);
  pinMode(PINO_PIR, INPUT);
  pinMode(PINO_LAMPADA, OUTPUT);
}

void loop() {
  int movimento = digitalRead(PINO_PIR);

  if (movimento == HIGH) {
    ultimaDeteccao = millis(); // Atualiza o instante da última detecção
    digitalWrite(PINO_LAMPADA, HIGH);
    Serial.println("Movimento detectado - lampada ligada");
  }

  // Apaga a lâmpada se o tempo sem detecção ultrapassar o limite
  if (millis() - ultimaDeteccao > TEMPO_ACESO) {
    digitalWrite(PINO_LAMPADA, LOW);
  }
}

MQ-2 — Alarme de vazamento de gás com corte de segurança

Ligação: MQ-2: VCC → 5V · GND → GND · A0 → pino analógico A1

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: MQ-2

// ===================================================
// Monitora a concentração de gás/fumaça (MQ-2) e
// aciona buzzer + válvula de corte em caso de vazamento
// ===================================================
#define PINO_MQ2 A1
#define PINO_BUZZER 5
#define PINO_VALVULA 6

const int LIMITE_GAS = 400; // Ajustar conforme calibração do ambiente

void setup() {
  Serial.begin(9600);
  pinMode(PINO_BUZZER, OUTPUT);
  pinMode(PINO_VALVULA, OUTPUT);
  Serial.println("Aquecendo o sensor MQ-2...");
  delay(20000); // Tempo mínimo de pré-aquecimento do elemento sensor
}

void loop() {
  int nivelGas = analogRead(PINO_MQ2);

  Serial.print("Nivel de gas: ");
  Serial.println(nivelGas);

  if (nivelGas > LIMITE_GAS) {
    digitalWrite(PINO_BUZZER, HIGH);   // Liga o alarme sonoro
    digitalWrite(PINO_VALVULA, HIGH);  // Aciona a válvula de corte de gás
    Serial.println("ALERTA: vazamento de gas detectado!");
  } else {
    digitalWrite(PINO_BUZZER, LOW);
    digitalWrite(PINO_VALVULA, LOW);
  }

  delay(1000);
}

Sensor Capacitivo de Umidade do Solo — Irrigação automática por umidade do solo

Ligação: Sensor capacitivo: VCC → 5V · GND → GND · AOUT → pino analógico A2

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: Sensor Capacitivo de Umidade do Solo

// ===================================================
// Liga a bomba de irrigação quando o solo está seco
// (sensor capacitivo de umidade do solo)
// ===================================================
#define PINO_SOLO A2
#define PINO_BOMBA 7

// Valores de calibração (medidos previamente no ar seco e na água)
const int VALOR_SECO = 620;
const int VALOR_MOLHADO = 300;
const int UMIDADE_MINIMA = 30; // % - abaixo disso, liga a irrigação

void setup() {
  Serial.begin(9600);
  pinMode(PINO_BOMBA, OUTPUT);
}

int lerUmidadePercentual() {
  int leitura = analogRead(PINO_SOLO);
  // Converte a leitura bruta para uma escala de 0% a 100%
  int percentual = map(leitura, VALOR_SECO, VALOR_MOLHADO, 0, 100);
  percentual = constrain(percentual, 0, 100);
  return percentual;
}

void loop() {
  int umidade = lerUmidadePercentual();

  Serial.print("Umidade do solo: ");
  Serial.print(umidade);
  Serial.println(" %");

  if (umidade < UMIDADE_MINIMA) {
    digitalWrite(PINO_BOMBA, HIGH); // Liga a bomba de irrigação
  } else {
    digitalWrite(PINO_BOMBA, LOW);  // Desliga a bomba
  }

  delay(2000);
}

YF-S201 — Medidor de consumo de água em litros

Ligação: YF-S201: VCC (vermelho) → 5V · GND (preto) → GND · SINAL (amarelo) → pino digital 2 (interrupção)

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: YF-S201

// ===================================================
// Calcula a vazão (L/min) e o volume total (L) de água
// usando os pulsos gerados pelo sensor YF-S201
// ===================================================
#define PINO_FLUXO 2 // Precisa ser um pino com suporte a interrupção

volatile unsigned long contadorPulsos = 0;
unsigned long ultimoCalculo = 0;
float volumeTotalLitros = 0;

// Função executada a cada pulso gerado pelo sensor
void contarPulso() {
  contadorPulsos++;
}

void setup() {
  Serial.begin(9600);
  pinMode(PINO_FLUXO, INPUT_PULLUP);
  // Chama contarPulso() a cada borda de subida do sinal
  attachInterrupt(digitalPinToInterrupt(PINO_FLUXO), contarPulso, RISING);
}

void loop() {
  if (millis() - ultimoCalculo >= 1000) { // Calcula a cada 1 segundo
    noInterrupts();
    unsigned long pulsos = contadorPulsos;
    contadorPulsos = 0;
    interrupts();

    // Fator do YF-S201: aproximadamente 450 pulsos por litro
    float vazaoLPM = (pulsos / 450.0) * 60.0;
    volumeTotalLitros += pulsos / 450.0;

    Serial.print("Vazao: ");
    Serial.print(vazaoLPM);
    Serial.print(" L/min | Volume total: ");
    Serial.print(volumeTotalLitros);
    Serial.println(" L");

    ultimoCalculo = millis();
  }
}

ACS712 — Monitor de corrente com proteção contra sobrecarga

Ligação: ACS712: VCC → 5V · GND → GND · OUT → pino analógico A3 (carga em série com IP+/IP-)

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: ACS712

// ===================================================
// Mede a corrente elétrica com o ACS712 (versão 20A)
// e desliga a carga em caso de sobrecorrente
// ===================================================
#define PINO_ACS712 A3
#define PINO_RELE_PROTECAO 8

const float SENSIBILIDADE = 0.100; // 100 mV/A para o modulo de 20A
const float TENSAO_REF = 5.0;
const float CORRENTE_LIMITE = 5.0; // Amperes

void setup() {
  Serial.begin(9600);
  pinMode(PINO_RELE_PROTECAO, OUTPUT);
  digitalWrite(PINO_RELE_PROTECAO, HIGH); // Carga ligada inicialmente
}

float lerCorrenteAmperes() {
  int leitura = analogRead(PINO_ACS712);
  float tensao = (leitura * TENSAO_REF) / 1023.0;
  // A saída fica centrada em VCC/2 (2,5V) quando a corrente é zero
  float corrente = (tensao - (TENSAO_REF / 2.0)) / SENSIBILIDADE;
  return corrente;
}

void loop() {
  float corrente = lerCorrenteAmperes();

  Serial.print("Corrente: ");
  Serial.print(corrente);
  Serial.println(" A");

  if (abs(corrente) > CORRENTE_LIMITE) {
    digitalWrite(PINO_RELE_PROTECAO, LOW); // Desliga a carga por segurança
    Serial.println("SOBRECORRENTE! Carga desligada.");
  }

  delay(500);
}

SW-420 — Alarme antifurto por detecção de vibração

Ligação: SW-420: VCC → 5V · GND → GND · DO → pino digital 3 (interrupção)

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: SW-420

// ===================================================
// Conta eventos de vibração e dispara um alarme se o
// número de eventos em 1 minuto ultrapassar o limite
// ===================================================
#define PINO_VIBRACAO 3
#define PINO_ALARME 4

volatile int eventosVibracao = 0;
unsigned long inicioJanela = 0;
const int LIMITE_EVENTOS = 5;
const unsigned long JANELA_MS = 60000; // 1 minuto

void registrarVibracao() {
  eventosVibracao++;
}

void setup() {
  Serial.begin(9600);
  pinMode(PINO_VIBRACAO, INPUT);
  pinMode(PINO_ALARME, OUTPUT);
  attachInterrupt(digitalPinToInterrupt(PINO_VIBRACAO), registrarVibracao, RISING);
  inicioJanela = millis();
}

void loop() {
  if (millis() - inicioJanela >= JANELA_MS) {
    Serial.print("Eventos de vibracao no periodo: ");
    Serial.println(eventosVibracao);

    if (eventosVibracao >= LIMITE_EVENTOS) {
      digitalWrite(PINO_ALARME, HIGH);
      Serial.println("ALERTA: possivel violacao detectada!");
    } else {
      digitalWrite(PINO_ALARME, LOW);
    }

    eventosVibracao = 0;
    inicioJanela = millis();
  }
}

MFRC522 (RFID) — Controle de acesso por cartão RFID

Ligação: MFRC522: SDA→10 · SCK→13 · MOSI→11 · MISO→12 · RST→9 · VCC→3.3V · GND→GND

Biblioteca: MFRC522 (miguelbalboa) — instale via Gerenciador de Bibliotecas

Página do sensor: MFRC522 (RFID)

// ===================================================
// Libera uma fechadura eletrônica apenas para
// cartões RFID cadastrados como autorizados
// ===================================================
#include <SPI.h>
#include <MFRC522.h>

#define PINO_SDA 10
#define PINO_RST 9
#define PINO_FECHADURA 8

MFRC522 leitor(PINO_SDA, PINO_RST);

// UID de um cartão autorizado (ajustar conforme o cartão do usuário)
byte uidAutorizado[4] = {0xDE, 0xAD, 0xBE, 0xEF};

void setup() {
  Serial.begin(9600);
  SPI.begin();
  leitor.PCD_Init();
  pinMode(PINO_FECHADURA, OUTPUT);
  digitalWrite(PINO_FECHADURA, LOW);
  Serial.println("Aproxime um cartao RFID...");
}

bool cartaoAutorizado(byte *uidLido, byte tamanho) {
  if (tamanho != 4) return false;
  for (byte i = 0; i < 4; i++) {
    if (uidLido[i] != uidAutorizado[i]) return false;
  }
  return true;
}

void loop() {
  // Verifica se existe um novo cartão presente
  if (!leitor.PICC_IsNewCardPresent() || !leitor.PICC_ReadCardSerial()) {
    return;
  }

  if (cartaoAutorizado(leitor.uid.uidByte, leitor.uid.size)) {
    Serial.println("Acesso liberado!");
    digitalWrite(PINO_FECHADURA, HIGH);
    delay(3000); // Mantém a fechadura destravada por 3 segundos
    digitalWrite(PINO_FECHADURA, LOW);
  } else {
    Serial.println("Cartao nao autorizado.");
  }

  leitor.PICC_HaltA(); // Encerra a leitura deste cartão
}

Encoder Incremental KY-040 — Navegação de menu em display com encoder rotativo

Ligação: KY-040: CLK → pino digital 2 · DT → pino digital 3 · SW → pino digital 4 · + → 5V · GND → GND

Biblioteca: Nenhuma biblioteca externa necessária

Página do sensor: Encoder Incremental KY-040

// ===================================================
// Lê a rotação e o botão do encoder KY-040 para
// navegar entre opções de um menu
// ===================================================
#define PINO_CLK 2
#define PINO_DT 3
#define PINO_SW 4

int opcaoMenu = 0;
const int TOTAL_OPCOES = 5;
int ultimoEstadoCLK;

void setup() {
  Serial.begin(9600);
  pinMode(PINO_CLK, INPUT);
  pinMode(PINO_DT, INPUT);
  pinMode(PINO_SW, INPUT_PULLUP);

  ultimoEstadoCLK = digitalRead(PINO_CLK);
}

void loop() {
  int estadoCLK = digitalRead(PINO_CLK);

  // Uma mudança no CLK indica que o eixo girou um passo
  if (estadoCLK != ultimoEstadoCLK && estadoCLK == LOW) {
    // Compara CLK e DT para saber o sentido da rotação
    if (digitalRead(PINO_DT) != estadoCLK) {
      opcaoMenu++; // Girou no sentido horário
    } else {
      opcaoMenu--; // Girou no sentido anti-horário
    }
    opcaoMenu = constrain(opcaoMenu, 0, TOTAL_OPCOES - 1);

    Serial.print("Opcao selecionada: ");
    Serial.println(opcaoMenu);
  }
  ultimoEstadoCLK = estadoCLK;

  // Verifica se o botão do encoder foi pressionado (confirma seleção)
  if (digitalRead(PINO_SW) == LOW) {
    Serial.print("Opcao confirmada: ");
    Serial.println(opcaoMenu);
    delay(300); // Debounce simples do botão
  }
}
